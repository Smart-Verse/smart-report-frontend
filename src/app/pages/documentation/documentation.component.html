01

Como o SmartReport funciona

Você organiza templates em repositórios, cria o layout com tecnologias web e envia um JSON. O SmartReport combina esses elementos e devolve um PDF A4 pronto para uso.

02

Crie seu primeiro relatório

1

Crie um repositório

Na Biblioteca, use “Novo repositório” para agrupar templates relacionados, como Financeiro ou Recursos Humanos.

2

Adicione um template

Selecione o repositório e clique em “Novo template”. Informe um nome claro para encontrá-lo depois.

3

Abra no Studio

Clique no card do template. Edite os quatro arquivos, salve e use “Visualizar” para conferir o PDF.

03

Os arquivos do Studio

HTML

template.html

Estrutura do documento. Use interpolação e diretivas diretamente no markup.

CSS

styles.css

Aparência na tela e no PDF. Prefira medidas previsíveis e regras específicas de impressão.

JS

script.js

Métodos auxiliares do template, como formatação de valores e datas.

JSON

data.json

Dados usados na visualização do Studio. Na integração, podem ser substituídos pelo payload da API.

05

Gere relatórios pela API

Crie uma credencial em Minha conta → Chaves de API. Ela será exibida somente uma vez. Envie a chave no header X-API-Key, junto do UUID do template e dos dados de produção. Se data for null, o JSON salvo no Studio será usado.

06

Boas práticas

  • Use o JSON de exemplo com a mesma estrutura enviada pela sua aplicação.
  • Teste textos longos, listas vazias e valores opcionais antes de publicar.
  • Use CSS de impressão e evite larguras maiores que uma página A4.
  • Não coloque segredos, tokens ou dados sensíveis dentro do template.
  • Salve antes de visualizar para garantir que o backend use a versão atual.
